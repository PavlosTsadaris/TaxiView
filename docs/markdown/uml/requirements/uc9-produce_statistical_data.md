# Use case 9 - Παραγωγή Στατιστικών Στοιχείων
**Πρωτεύων Actor:** Ομάδα διαχείρισης

**Ενδιαφερόμενοι:**

- **Ομάδα διαχείρισης**: Θέλει να επεξεργάζεται τα δεδομένα που έχουν αποθηκευτεί στο σύστημα, ώστε να παράγει στατιστικά στοιχεία για την παρακολούθηση και τη βελτιστοποίηση της λειτουργίας της εφαρμογής.
- **Πελάτης**: Θέλει να ενημερωθεί για τα στατιστικά δεδομένα της εφαρμογής.
- **Οδηγός ταξί**: Θέλει να ενημερωθεί για τα στατιστικά δεδομένα της εφαρμογής.

**Προϋποθέσεις**: 
  - Η ομάδα διαχείρισης να έχει συνδεθεί στην εφαρμογή.
  - Η ομάδα διαχείρισης να έχει πρόσβαση στα δεδομένα της εφαρμογής.

## Βασική Ροή

1. Η ομάδα διαχειρίσης επιλέγει την ενέργεια «Στατιστικά στοιχεία».
2. Η ομάδα διαχείρισης επιλέγει τα επιθυμητά φίλτρα αναζήτησης.
3. Το σύστημα συγκεντρώνει τα απαραίτητα δεδομένα.
4. Το σύστημα εφαρμόζει τα φίλτρα και αναλύει τα δεδομένα.
5. Το σύστημα εμφανίζει τα στατιστικά στοιχεία στην οθόνη.

## Εναλλακτικές Ροές
_*Σε οποιοδήποτε σημείο το λογισμικό καταρρέει._

1. Η εφαρμογή εμφανίζει μήνυμα σφάλματος.
2. Η διαδικάσια παραγωγής στατιστικών δεδομένων ξεκινάει από την αρχή.

_2α. Η ομάδα διαχείρισης επιλέγει ως φίλτρο την Απόδοση στόλου και Διαδρομών_
